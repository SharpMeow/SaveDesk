# Community guidelines

Help make SaveDesk a welcoming place to learn and contribute.

- Be respectful and constructive. Discuss the work, not personal attributes.
- Welcome beginners and differing experiences. Explain assumptions and give actionable feedback.
- Do not harass, threaten, discriminate, share private information, or post spam.
- Do not post someone else's personal data or saved collection without permission.

These guidelines apply to this repository's issues, pull requests, and other project spaces. Maintainers may edit or remove content, close discussions, or restrict participation to address disruptive behavior, with the response proportionate to the conduct.

To flag a problem, use GitHub's reporting tools or ask a maintainer for a private contact without repeating harmful content or disclosing private details. This volunteer project cannot promise a response time. See [SECURITY.md](SECURITY.md) for software vulnerabilities.
