You’re exploring sample saves. Import your collection to make this space yours. Imported files stay in this browser until you publish them.

Bring your saves along.

Import like.js from an extracted X archive, a JSON array of saves, or a Savedesk backup. Choose Likes or Bookmarks when importing an unlabelled file.

JSON items can include id, text, author, url, source, tags, created_at. Source is like or bookmark. Tags are an array of strings.

To publish your collection, use Export for publishing, then commit the downloaded collection.json beside this page in your GitHub repo. That file will be public. Personal reading progress stays in your browser.

This prototype imports files only. It does not connect to X or fetch missing text, images, threads, or deleted posts. Archive contents may be incomplete. An X archive should not be assumed to contain bookmarks.

Your collection is stored locally in this browser. Use Export library for a backup before clearing browser data.
